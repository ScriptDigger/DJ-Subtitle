# [DJ Subtitle](https://scriptdigger.github.io/DJ-Subtitle/)

**DJ Subtitle** is an After Effects tool for creating and generating animated subtitle typography.

Import an **SRT file** or create subtitles manually, edit text and timing, choose a typography style, and generate the final animated composition automatically.

## Features

- Import & export SRT subtitles
- Create and edit subtitles inside After Effects
- Marker-based subtitle timing
- Multiple typography styles and layouts
- Automatic animated typography generation
- Global font, color, and animation controls
